# تحديث المرحلة الأولى — فرع التطوير

- مراجعة مشروع Supabase الحالي والجداول الأساسية وسياسات RLS.
- استعلامات المشرف أصبحت تقرأ بيانات profiles وparent_student وprogress وinvitations على دفعات بدل الإيقاف الصامت عند حد الصفوف.
- تحسين حساب ملخصات الطلاب من معالجة متكررة إلى تجميع خطي.
- إضافة بحث، ترتيب، صفحات (30 طالبًا لكل صفحة)، وعرض موجز لحالة الدعوات.
- تحميل آخر 100 تقرير فقط في قائمة تقارير المشرف لتقليل الاستهلاك.
- إضافة GitHub Actions للفحص الأولي لملفات HTML وJavaScript دون أي أسرار.
- إضافة ملف Cloudflare Pages `_headers` ودليل تشغيل وتجربة منفصلة.
- لا توجد أي تغييرات على بيانات الطلاب أو مخطط Supabase ضمن هذا التحديث.
- **المطلوب قبل الدمج:** مراجعة الاختبارات، ثم اختبار الأدوار بحسابات وهمية، ثم النسخ الاحتياطي المستقل.

> لم يتم نشر Cloudflare لأن الحساب غير متصل مباشرة بأداة تنفيذ هنا.
